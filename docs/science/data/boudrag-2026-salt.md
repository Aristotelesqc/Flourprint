# Boudrag 2026: salt x flour matrix (rheofermentometer)

Data file: `boudrag-2026-salt.csv` (12 rows: white, fibre-fortified and wholemeal x 4 salt levels), from Table 5 of the paper. Extracted by script from the full-text XML on 2026-10-30, replacing an earlier transcription through the Gemini report that did not match the paper. The peak maximum time and torque columns of Table 5 (gluten aggregation) and its significance letters are not kept.
