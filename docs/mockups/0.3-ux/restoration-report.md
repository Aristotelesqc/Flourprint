## Visual review findings

Codex reviewed the 26 matched candidate/reference views and the component catalogue, then replayed
the changed controls. The final review found and corrected two more presentation losses before
publication: the selected template’s description was missing, and unchecked weighing outlines
were too faint. A final diagnostic detail review also removed the repeated title/badge from embedded warning panels; the parent accordion retains the status, and expanded content keeps its explanatory text. Descriptions now reuse the application’s translated source text; unchecked borders
use the existing muted-ink token with a measured minimum 3:1 contrast in all three themes.

The result retains round 2’s warm card/summary composition, metric pills, group hierarchy, anchored
menu and dominant preparation time. The changes below are deliberate, visible and reviewable:

- Actual core fixtures replace round 2’s fabricated values/history: Shokupan has 314 g flour, 699 g
  dough and 229.4 g known water contribution. Tangzhong allocations/ratios are resolved by core;
  there is no copied 14 g evaporation loss. Partial water/fat/sugar contributions use a lower-bound
  marker and retain their known/estimated/unknown details.
- Read-only values are text; editing remains in the same sections. Ingredient percentages sit
  beneath names and edit fields occupy a separate row, preserving readable names at larger text.
  The flour blend changes atomically in its sheet rather than through a single share that cannot
  independently sum to 100%.
- At 360px/130%, B’s header wraps to preserve the full title and action labels. The recipe section
  strip scrolls horizontally, with keyboard navigation; all four long labels are not visible at once.
  The contextual-versus-global navigation decision stays open for the owner.
- Build identity is a single readable, copyable caption above the footer, rather than broken
  fragments in the header. The actual bakery code name/channel are retained.
- Planning displays actual core startAt/readyBy results and a complete end date. The ordinary
  source fixture has 10 steps and a different phase/duration from round2; supplemental cooking
  views expose frozen oven/mode/vessel settings. A numerical/fixture difference is not a visual win.
- Preparation retains quick actions and upcoming/completed groups. Finishing the last stage does
  not silently finish or restart a preparation. Explicit Finish records the chosen result; history
  distinguishes actual preparations from recipe revisions, without inventing a rating.
- Template selection keeps a translated description for the selected card, actual metrics,
  expandable original basis/source and a separate Create action. Choosing a card alone creates nothing.

This is Codex’s visual/usability assessment for the named artifact. The owner’s visual acceptance,
navigation selection and the other policy choices below remain open.
