## Defects found during this slice, fixed before publication

- Enlarging passive pills initially reduced list density. Compact card spacing and filter padding
  restore four complete cards; the existing density assertion was kept.
- At 360 px / 130%, the A recipe overflow button initially wrapped onto a second footer row.
  Reduced horizontal padding preserves all four actions on one aligned row. A new assertion
  covers this in all three themes.
- The menu's close target overlapped the first action. The first action now reserves that space,
  all menu action rows keep at least 48 px targets, and open-menu rectangles are checked for
  overlap at both sizes and in both navigation variants.
- Linux CI run 420 passed the app suite but found the fourth card at 805 px against a 770 px
  content boundary. The platform font wrapped filters onto a second row. The filter strip now
  scrolls horizontally without shrinking text/targets; a DejaVu-font stress matrix and the
  unchanged four-card density assertion cover the correction. The A toolbar also has sufficient
  spacing tolerance for that wider font.
- The keyboard-selected last filter initially received focus without becoming fully visible.
  Its selected element now scrolls into view after the React commit. End/Home tests assert actual
  button bounds within the strip, in both font matrices.
- Decorative pressed content shrinks while the native hit box stays 48 px.
- The component reduction bridge respects both OS preference and manual reduction, including
  preference changes; a standard review toggle cannot override the OS.

## Guide corrections

The review corrected misleading claims rather than marking drafts approved:

- Button/icon-button: physical hit versus painted shape, native attributes/focus, destructive
  confirmations, selected motion timing and consumer fit checks.
- Bottom bar: A/B are consumer choices; B does not necessarily add a second contextual footer.
- Group card/step node: decorative icons do not invent accessible status words; consumers supply
  textual status where needed.
- Ingredient row: percentage basis is supplied explicitly; non-editing row/checkbox toggles and
  the end-cell propagation boundary are described accurately.
- Number field: invalidity callback polarity, raw/committed precision, reset behavior and the
  requirement to name units in label/hint because adornments are aria-hidden. The guide now states the actual 36 px base input height; it does not falsely claim the surrounding row enlarges its hit area.
- Icon: the provisional set is not presented as the owner's final pictogram-source choice.
- Recipe card, hero summary, prep hero, timeline, warning banner, checkbox, badge, metric pill,
  surface, tabs and overlays: actual props, display-only/domain boundary, embedded-header behavior,
  20 px checkbox paint, elevation and accessibility responsibilities checked.
